A responsive web application designed for real-time meteorological tracking and forecasting for cities worldwide, powered by a live weather API. Built using modern React and a custom CSS design system, it features local state persistence, an interactive saved-cities dashboard with a strict six-location limit, and custom in-app notification toasts. The user interface blends practical data visualization with immersive atmospheric design, incorporating dynamic weather condition summaries and an ambient animated globe background complete with a periodic paper plane flight.
